# Circuit Atlas HTML viewer

[Download Circuit-Atlas-HTML.zip](https://github.com/Will1234-pixel/Jack/raw/refs/heads/codex/circuit-atlas-html/downloads/Circuit-Atlas-HTML.zip)

If GitHub asks, sign in with the account that has access to this repository. You can also open `Circuit-Atlas-HTML.zip` above and select **Download raw file**.

1. Download the ZIP (about 20 MB) and choose **Extract All** in Windows.
2. Open `Circuit-Atlas-Standalone.html` in a current Microsoft Edge or Google Chrome.
3. Click **Try supplied example**, then click `098.275` or its attached wire on page 23. Page 67 opens with `039.377` highlighted. Use the viewer's **Back** button to return.

No Python installation or application server is needed to open this prepared drawing set. All 135 pages are embedded in the HTML. Keep your notes and manual link reviews by using **Export review backup**; they are not written into the HTML itself.

The package includes instructions, the reference audit and a guide to the example circuit. There are 128 validated CAD overlays and one documented reciprocal circuit pair. Other references may need manual review; repeated labels alone do not establish connectivity. Importing another PDF/DXF set requires a newly prepared package or the separate importing application.

Four standalone browser tests passed. The managed test browser blocks local file URLs, so tests served only this HTML document over a local connection; direct Windows double-click launching remains unverified.
